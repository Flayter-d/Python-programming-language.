# ДЗ 3. Главы 3.2–3.3: циклы `while` и `for in`

Шестнадцать задач из задачника: восемь к главе 3.2 и восемь к главе 3.3.

В задачах 1–8 нужен цикл `while`. Программа читает числа до нуля и разбирает число по цифрам.
В задачах с попытками цикл прерывается через `break`, а блок `else` у цикла срабатывает, когда
попытки закончились. В задачах 9–16 нужен цикл `for in`: он перебирает строку, список или числа
из `range()`. По ходу перебора программа считает сумму или произведение и ищет минимум.

`input()` внутри цикла выполняется на каждом повторе, поэтому его подсказка выводится перед
каждым вводом. В задачнике данные вводятся без подсказок, в этом ДЗ у каждого `input()` есть
текст подсказки.

Главы справочника: [3.2 Цикл while с предусловием](https://python-theory-makarov.vercel.app/temy/20-while/index.html),
[3.3 Цикл for in: перебор значений](https://python-theory-makarov.vercel.app/temy/21-for-in/index.html)
